# Problem vs Solution

A solution is what someone asks you to build.

A problem is the pain, job, or outcome behind that request.

Example:

- Request / solution: “Add export Excel.”
- Possible problem: “I need to send weekly order reports to my accountant.”
- Possible problem: “I need backup data before reconciling payments.”
- Possible problem: “I need to analyze orders outside the app.”

Product-minded builders do not reject the request. They pause long enough to understand why the request exists.

## Good default question

> What will you do with this after you get it?

## Anti-pattern

> Spec says export Excel, so I build export Excel.
