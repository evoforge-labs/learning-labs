Hãy tưởng tượng bạn có tờ đơn điền sẵn: "Tôi muốn xem thông tin của người dùng **\_\_\_**." Bạn muốn người dùng điền tên vào chỗ trống. Nhưng một kẻ phá hoại điền vào: "tất cả mọi người, hãy xóa toàn bộ bảng". Nếu bạn đọc nguyên xi tờ đơn đó ra tòa — bạn vừa tự tay ra lệnh xóa dữ liệu.

Đó là SQL injection: **đầu vào của người dùng bị nhúng thẳng vào câu lệnh SQL, biến dữ liệu thành mệnh lệnh**.

## Là gì

**SQL Injection (SQLi)** xảy ra khi ứng dụng nhận đầu vào từ người dùng và ghép trực tiếp vào câu lệnh SQL mà không lọc hay tách biệt. Kẻ tấn công lợi dụng điều này để đọc dữ liệu không được phép, sửa/xóa dữ liệu, hoặc thậm chí chiếm quyền điều khiển database.

## Ví dụ thật

Đây là đoạn code **dễ bị tấn công**:

```python
# NGUY HIỂM — đừng bao giờ làm thế này
username = request.form['username']
query = "SELECT * FROM users WHERE username = '" + username + "'"
db.execute(query)
```

Nếu kẻ tấn công nhập `username` là `' OR '1'='1`, câu lệnh trở thành:

```sql
SELECT * FROM users WHERE username = '' OR '1'='1'
```

Điều kiện `'1'='1'` luôn đúng — kết quả: toàn bộ bảng `users` bị trả về. Tệ hơn nữa, nhập `'; DROP TABLE users; --` có thể xóa sạch dữ liệu.

**Cách phòng — dùng parameterized query:**

```python
# AN TOÀN — dữ liệu và câu lệnh được tách biệt hoàn toàn
username = request.form['username']
query = "SELECT * FROM users WHERE username = ?"
db.execute(query, (username,))
```

Với parameterized query, database nhận câu lệnh SQL và dữ liệu **tách biệt**. Dù người dùng nhập gì, nó cũng được xử lý như *dữ liệu thuần*, không bao giờ được diễn giải như câu lệnh SQL.

<Callout title="Cẩn thận">
Nhiều builder nghĩ "mình đã escape ký tự đặc biệt là an toàn rồi". Không đủ — escaping thủ công dễ bỏ sót trường hợp, đặc biệt với encoding nhiều lớp hoặc các database engine khác nhau. Parameterized query là cách duy nhất đáng tin cậy.
</Callout>

<Callout title="Nhớ nhé">
Không bao giờ ghép chuỗi đầu vào người dùng vào câu lệnh SQL. Luôn dùng parameterized query (prepared statement) — mọi ngôn ngữ, mọi ORM đều hỗ trợ sẵn.
</Callout>
