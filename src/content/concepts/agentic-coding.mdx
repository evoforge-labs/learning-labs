Autocomplete đoán từ tiếp theo bạn gõ — như bàn phím điện thoại. Agentic coding thì khác: bạn nói "fix cái lỗi này", agent *tự đọc file*, *chạy test*, *sửa code*, *chạy lại test* — và báo cáo kết quả. Hai thứ trông giống nhau nhưng bản chất hoàn toàn khác.

## Là gì

**Agentic coding** là cách lập trình trong đó agent AI tự chạy qua một vòng lặp nhiều bước: thu thập context → hành động (đọc file, sửa code, chạy lệnh) → xem kết quả → lặp lại — cho đến khi xong việc.

Ba thứ tạo nên một coding agent:
- **Model**: LLM suy luận và quyết định bước tiếp theo
- **Harness**: bộ khung cung cấp tool, quản lý context, chạy vòng lặp (xem [concept-agent-harness](/concepts/agent-harness))
- **Vòng lặp**: agent *chạy code nó viết* — đây là điểm khác biệt cốt lõi với autocomplete

## Ví dụ thật

Bạn gõ trong Claude Code: *"Thêm pagination cho API `/users`, dùng cursor-based, viết test luôn."*

Agent không dừng lại chờ bạn chỉ từng bước. Nó:
1. Đọc file router hiện tại để hiểu cấu trúc
2. Xem schema database để biết field nào dùng làm cursor
3. Viết code pagination
4. Viết test
5. Chạy test — nếu fail, đọc lỗi và tự sửa
6. Báo lại khi pass

Bạn không chỉ định nó đọc file nào. Nó tự quyết định cần biết gì.

<Callout title="Góc kỹ thuật">
Claude Code mô tả vòng lặp gồm ba giai đoạn liền nhau: **gather context** (đọc file, search code, hiểu codebase) → **take action** (sửa file, chạy lệnh, gọi tool) → **verify results** (chạy test, đọc output, điều chỉnh). Ba giai đoạn này lặp liên tục, không phải một lần — agent tự quyết định khi nào đủ.
</Callout>

<Callout title="Nhớ nhé">
Agent chạy code nó viết — đây không phải autocomplete. Đó là lý do tại sao bạn cần *verify*, không chỉ đọc.
</Callout>
