Khi bạn vào khách sạn lần đầu, lễ tân kiểm tra hộ chiếu và đưa cho bạn một thẻ từ. Từ đó trở đi, bạn dùng thẻ từ để vào phòng, lên gym, vào nhà hàng — không cần xuất trình hộ chiếu mỗi lần nữa. Nhà hàng trong khách sạn không cần biết tên bạn là gì, chỉ cần thẻ từ đó là hợp lệ.

OAuth làm đúng điều đó cho phần mềm.

## Là gì

**OAuth 2.0** là giao thức *ủy quyền* (authorization): cho phép một ứng dụng truy cập tài nguyên của bạn ở một dịch vụ khác — *mà không cần biết mật khẩu của bạn*. Khi bạn nhấn "Đăng nhập bằng Google", app của bạn không nhận mật khẩu Google của bạn — nó nhận một *access token* có giới hạn thời gian và phạm vi.

**OpenID Connect (OIDC)** là lớp xác thực (authentication) xây trên OAuth 2.0. OAuth nói "user này được làm gì", OIDC nói thêm "user này là ai". Hầu hết "đăng nhập bằng Google/GitHub" thực ra dùng OIDC.

**SSO (Single Sign-On):** Đăng nhập một lần, dùng được nhiều app. Google Workspace là ví dụ điển hình: đăng nhập vào Gmail xong, vào Google Drive, Google Docs đều không cần đăng nhập lại.

## Ví dụ thật

Bạn build một SaaS và muốn thêm "Đăng nhập bằng GitHub":

1. User nhấn nút → app redirect đến GitHub với `client_id` và `scope` (ví dụ: chỉ cần đọc email).
2. GitHub hỏi user: "App X muốn đọc email của bạn, đồng ý không?"
3. User đồng ý → GitHub redirect về app với một `authorization code`.
4. App server đổi `code` lấy `access token` (và `id_token` nếu dùng OIDC).
5. App dùng token để lấy thông tin user từ GitHub API — xong.

Mật khẩu GitHub của user không bao giờ chạm vào server của bạn.

**Khi nào solo builder nên dùng OAuth/SSO thay vì tự build auth?**

Gần như luôn luôn. Tự build auth từ đầu = tự quản lý mật khẩu, session, MFA, account recovery. Dùng thư viện như Auth0, Clerk, Supabase Auth hay NextAuth giúp bạn có OAuth, SSO, MFA trong vài giờ.

<Callout title="Góc kỹ thuật">
OAuth 2.0 là *authorization* framework, không phải authentication. Nếu chỉ dùng OAuth thuần (không có OIDC), bạn biết user được làm gì nhưng không chính xác biết user là ai. OIDC thêm `id_token` (JWT) chứa thông tin danh tính. Khi build "Login with Google", bạn đang dùng OIDC trên nền OAuth 2.0.
</Callout>

<Callout title="Nhớ nhé">
OAuth = ủy quyền không chia sẻ mật khẩu. OIDC = OAuth + biết user là ai. SSO = đăng nhập một lần dùng nhiều nơi. Solo builder nên dùng auth service có sẵn thay vì tự build từ đầu.
</Callout>
