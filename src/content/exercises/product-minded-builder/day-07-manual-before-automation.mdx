# Day 07: Manual Before Automation

## Scenario

Bạn muốn tạo feature tự động gửi weekly business report cho shop nhỏ.

<Ask>
Cách nào test nhu cầu trước khi build automation full?

A. Tạo form để user request report, bạn generate thủ công bằng SQL/Sheet.  
B. Gửi 5 report mẫu cho 5 user và hỏi họ có muốn nhận hàng tuần không.  
C. Build scheduler, report builder, template editor, billing ngay.  
D. Làm một script chạy local cho 1 user đầu tiên.  
E. Hỏi user report hiện tại họ tự làm thế nào.
</Ask>

<Explain>
Correct: A, B, D, E

A/B/D/E giúp học workflow và willingness. C có thể đúng sau khi validate, nhưng quá sớm.
</Explain>

## Single choice

Manual process lúc đầu có lợi gì nhất?

A. Không cần quan tâm chất lượng.  
B. Hiểu workflow thật trước khi đóng băng nó thành code.  
C. Để khỏi bao giờ phải build.  
D. Làm sản phẩm trông chuyên nghiệp hơn.

<Explain>
Best: B
</Explain>
